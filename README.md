# Macroeconomic Cloud Data Platform

This platform follows a layered cloud data warehouse architecture. Python scripts extract macroeconomic indicators from the World Bank and IMF APIs, save them as Parquet files, and upload them to Google Cloud Storage. The data is then loaded into the BigQuery raw layer, where SQL models built with dbt transform and clean the data into staging views before creating an analytics-ready fact table. Automated dbt tests validate data quality by checking for duplicates, null values, and join coverage, ensuring the warehouse contains reliable, analysis-ready data.

---
## Data Architecture

The data architecture for this project follows the **Medallion Architecture**, consisting of **Raw (Bronze)**, **Staging (Silver)**, and **Analytics (Gold)** layers:

1. **Bronze (Raw) Layer**: Macroeconomic data is extracted from the World Bank and IMF APIs using Python, stored as Parquet files in Google Cloud Storage, and loaded into the BigQuery `raw` dataset without business transformations.

2. **Silver (Staging) Layer**: SQL models built with dbt clean, standardize, and validate the raw data. Data types are cast appropriately, records with missing key fields are filtered out, and only relevant observations are retained to create consistent staging views.

3. **Gold (Analytics) Layer**: dbt transforms the staging data into an analytics-ready fact table in the BigQuery `analytics` dataset. The final model combines GDP, population, GDP growth, and CPI data, derives additional metrics such as GDP per capita and growth categories, and serves as a curated dataset for reporting and analysis. Automated dbt tests verify data quality through duplicate, null, and join coverage checks.

## Repository Structure
```
macro-data-platform1/
│
├── models/
│   ├── staging/             # SQL models that clean and standardize raw data.
│   │   ├── stg_world_bank.sql
│   │   └── stg_imf.sql
│   │
│   ├── marts/               # Analytics-ready fact table for reporting and analysis.
│   │   └── fct_macroeconomic_indicators.sql
│   │
│   └── sources.yml
│
├── tests/                   # Custom dbt data quality tests.
│   ├── duplicate_check.sql
│   ├── join_coverage.sql
│   └── null_check.sql
│
├── analysis/                # Exploratory and profiling SQL queries that are not tests.
│   └── profiling.sql
│
├── data/                    # Local Parquet files generated during ingestion.
│   ├── world_bank.parquet
│   └── imf.parquet
│
├── target/                 # Generated by dbt (excluded from Git)
├── logs/                   # Generated by dbt (excluded from Git)
│
├── world_bank.py           # Extract World Bank data
├── imf.py                  # Extract IMF data
├── storage.py              # Upload files to Google Cloud Storage
├── bigquery_loader.py      # Load Parquet files into BigQuery
├── run_pipeline.py         # Orchestrates ingestion pipeline
├── config.py               # Project configuration
│
├── dbt_project.yml         # dbt project configuration.
├── packages.yml            
├── requirements.txt
├── .gitignore
└── README.md               # Project overview
```
